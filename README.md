# 聊天产物 · 独立 Buzz 插件

在当前聊天标题栏点击 **产物**，查看当前频道发布的文件、图片、视频及网站链接。
使用官方插件接口；无需修改、重编译或替换 Buzz.app。

## 安装

推荐在聊天中的官方安装／更新卡片点击 **Review → Install plugin / Update plugin**。
Git 来源：`https://github.com/miaopantao/opcb-chat-artifacts-plugin.git`，分支 `main`。
卡片固定具体提交；安装和更新都由本人确认。以下为本机文件夹安装的替代入口：

1. 在 Buzz 打开 **Settings → Plugins → Manage plugins → Add**。
2. 在 **Add from folder** 下点击 **Browse**，选择包含 `manifest.json` 和 `plugin.js` 的本文件夹。
3. 阅读权限说明后，由本人点击 **Install plugin**。这是 Buzz 的安装要求，Agent 不能代点。
4. 回到任意已连接的聊天，点击标题栏的 **产物**。

安装后插件保存在 Buzz 的插件目录；正常升级同一官方客户端通常不需要重新安装。
文件夹安装后修改同一文件夹源码，可通过 Plugin development 的 `plugin_reload` 重载。
Git 安装则通过更新卡片审阅新的固定提交，不能用文件夹重载。
不要拖入文件夹安装：拖入会复制文件，丢失开发文件夹重载关联。

## 当前版本 0.3.0

修复“加载更早产物后最新产物消失”：现在累计追加，不再翻页替换。
已加载的清单和已读文档预览保存在本机 IndexedDB；重开先显示缓存，再按上次游标同步新增和变更。
同步失败保留已有列表；保存失败会提示，不把内存内容宣称为已落盘。

- 单次读取 12 条消息，加载更早历史后合并、去重并保存；历史游标一并保存，重开可接着向前加载。
- 搜索、类型与范围筛选覆盖所有已加载的产物；未读取历史仍需点击“加载更早产物”。
- 增量同步包含编辑、删除及同秒边界。只为新增／变更对象读取宿主的精确折叠结果；无法定位的旧编辑删除例外修复已缓存对象。
- 已读文本／Markdown 前 64 KiB 本地复用；图片、视频及完整附件沿宿主按需加载，不提前下载整段视频，不承诺完整文件离线。

沿用原产物看板设计：

依据原产物看板 `Artifacts.tsx` / `Artifacts.module.css` 恢复布局：

- 顶部 **Agent 产物 / 已分享文件 / 全部文件**，默认 Agent 产物；横向类型筛选。
- 搜索、收藏筛选与卡片／列表切换；宽屏三列、中屏两列、窄屏一列。
- 卡片文件图标与文件名标题、操作菜单、14rem 内容预览；图片顶端裁切、视频播放提示。
- 卡片菜单收藏／取消收藏和回到原消息；打开详情后返回保留列表与键盘焦点。
- 本机收藏使用标准 Web Storage，仅操作插件专用键，按社区、账号和频道隔离；保存失败会提示。
  不同步到其他设备，也不读取或迁移旧客户端收藏。
- Markdown 恢复标题、段落、列表、加粗与代码块的基础排版；HTML 仍作文本。
  不是完整 GFM 渲染器，表格、嵌套列表与文档内交互链接尚未迁入。

- 当前频道的已发布消息，包含普通消息和线程回复，新增与更早产物累计保留。
- 所有产物、Agent 产物和共享文件；按图片、视频、文档、网站、链接及其他文件分类。
- 已加载清单的名称搜索、图片惰性缩略图、产物详情与回到原消息。
- 图片放大和视频交给宿主的原生消息及媒体查看器；列表不预加载视频。
- 可见卡片惰性读取纯文本/Markdown/代码文件前 64 KiB；详情支持重试。HTML 和代码不会执行。

## 兼容边界与旧版差异

- 已固定核对官方 **0.7.0-preview.267.1**，源码 commit
  `0c66ed068a5d60139a8041558993b45f3351069a`。未验证后续 1.0.0 或其他平台。
- 插件使用 API v1 以及宿主公开的频道、精确消息读取和原生消息组件。
  官方将部分会话 UI 标为 host-matched preview，**不承诺跨版本 SDK 稳定**。
  未来接口有变化时需更新本插件；不需要维护整套客户端分叉。
- 搜索覆盖本机已加载清单，不把尚未读取的历史称为完整索引。
- 旧版的本机网站截图/快照缓存没有找到对应公开插件接口，本版通过原消息打开网站。
  不调用客户端私有 Tauri 命令，不修改官方 CSP。
- 原客户端收藏数据没有迁移；原数据保持原样。新增上传继续使用聊天原有附件按钮。
- 查看详情沿插件面板与原生消息组件；尚未复刻原客户端全屏专用文档查看器。
- 只读取当前聊天，不读取 Agent 文件系统，不迁移用户库；保存宿主已折叠结果作为本地产物索引，不另建签名或消息写入链路。

## 生命周期与权限

`session.readRemote` 用于发现新增消息、编辑／删除目标 ID 与分页游标；内容一律取宿主
`session.thread(channelId, id, { exact: true })` 的已折叠 target。
编辑、删除、署名、附件和阅读权限由原宿主决定，插件不从旧事件内容自行重建消息。
最多保留 12 个精确 reader、最多 3 个并行 refresh，历史产物数量不占用额外 reader。
关闭、换账号/连接代际或撤权会取消并释放。面板打开时由宿主 live 事件触发同步，不添加轮询。
缓存按社区、账号、频道隔离，仅在当前阅读权限已确认后展示；缓存不授予权限。
断开或切换账号清空当前展示，正常重连保留磁盘缓存；确认被撤权后清除该频道索引和文档缓存。
索引批次与游标在同一 IndexedDB 事务写入，失败不推进持久化游标；不静默淘汰旧产物。
关闭面板或重启不会删除已完成保存的数据；清除应用网站数据或系统回收存储仍可能移除缓存。

manifest 不申请命令、进程、通用文件系统或额外网络来源权限。
文本读取仅接受宿主规范媒体代理地址，并限制流式读取字节数。
插件仍是 Buzz 进程中的可信代码，不是浏览器沙盒。

## 验证

```sh
node --check plugin.js
node --test tests/*.test.js
```

Node 回归覆盖消息折叠来源、删除、回复、累计加载、重开、增量同秒边界、断网重试、
撤权、忽略 abort 的迟到返回、连接代际、缓存写入失败／损坏、资源释放与有界文档读取。
隔离 React 界面通过 EGO 测试搜索、分类、分页、详情、导航目标、
深浅主题、390px/125% 字号、撤权清空与 StrictMode 卸载清理。
隔离预览中的 Relay/原生消息与媒体是替身，**不代替真实宿主验收**。

首次安装后还需验证真实频道历史、私有附件、图片放大、视频、文档读取和来源跳转。
安装状态以官方更新卡片与 plugin_status 为准。
本地检查和隔离预览不代表 GitHub CI 或真实业务验收。
